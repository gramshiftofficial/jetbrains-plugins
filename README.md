## Reporting a bug

[Open a new issue](../../issues/new/choose) and include:

- the plugin name and version (Settings | Plugins | Installed),
- the IDE name and version (Help | About),
- what you did, what you expected, and what happened instead,
- for errors, the stack trace from Help | Show Log in Explorer/Finder (`idea.log`).

Please do not paste access tokens, passwords or other secrets.

If you prefer email, write to gramshift.official@gmail.com.

Licensing, trials, invoices and refunds are handled by JetBrains Marketplace.
More information: https://gramshift.com/plugins/
